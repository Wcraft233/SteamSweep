# SteamSweep

**Steam 深度清理工具**：帮你找回被卸载游戏偷走的硬盘空间。

游戏卸载了，但安装目录的残留文件和云存档还躺在硬盘里——几十 GB 空间就这么没了。SteamSweep 把它们找出来，勾选，一键清理。

## 下载

去 [Releases](https://github.com/Wcraft233/SteamSweep/releases) 下载 `steamsweep.exe`，双击即用，无需安装、无需配置。

## 它能做什么

- **安装残留清理**：找出所有已卸载游戏留下的安装目录（含没下完的下载、创意工坊内容、着色器缓存），按占用空间从大到小排好，最大的罪魁祸首一眼看到
- **存档管理**：列出所有游戏的存档，分好类——
  - **可安全删除**：游戏已卸载、云端还有副本的存档
  - **有丢失风险**：从没上传过云端的存档（红色标出，删之前想清楚）
  - **未卸载**：正在玩的游戏存档（默认折叠，不碍事）
- **卸载提醒**：你刚卸了游戏，它弹窗提醒"要不要顺手把存档也清了"
- **放心删**：所有删除都只进系统回收站，反悔了随时还原；云端存档永远不动

打开软件就自动开始扫描，游戏封面、中文名都给你配好，等十几秒结果就出来了。第二次启动有缓存，基本秒出。

## 进阶

- **命令行**：`steamsweep --cli` 输出扫描报告（终端摘要 + `steamsweep-report.json`）
- **设置**（左下角）：Steam 接口被网络阻断时可填本地代理；游戏名补不全可填 Steam API 密钥；有奇怪的存档目录可加自定义扫描路径
